# 609 Research Homebrew tap

Homebrew casks for [609 Research](https://609-research.github.io) apps.

## opa.notch

[opa.notch](https://github.com/609-RESEARCH/opa.notch): your day and your reminders in the MacBook notch.

```bash
brew install --cask 609-research/tap/opa-notch
```

Update with `brew upgrade --cask opa-notch`.
